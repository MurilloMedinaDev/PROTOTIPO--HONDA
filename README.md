# Protótipo em Cards - Honda Seguros

Protótipo estático de uma experiência de atendimento em cards.

## Publicação no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie os arquivos deste pacote para a raiz do repositório.
3. Acesse **Settings > Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch **main** e a pasta **/(root)**.
6. Salve e aguarde a publicação.

O arquivo `index.html` será carregado automaticamente como página inicial.

## Execução local

Abra o arquivo `index.html` em um navegador moderno.

## Observação

Este material é um protótipo de demonstração. Antes de publicar em um repositório público, revise os textos, telefones, links, marcas e quaisquer informações internas ou operacionais.
